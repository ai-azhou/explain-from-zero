# 样式库

每种风格一份样张：单文件网页，打开就自己播十几秒，演示这种风格下的讲解镜头怎么做到精致。样张只有画面，没有字幕、按钮、进度、出处这些页面上的东西。样张讲的都是风格自己（「线条每两帧抖一次」），不含任何领域内容。

**样张只教做法，不定颜色。** 每份样张的颜色来自它自己的主体（弹簧圈、茶壶、跑鞋……）；文件头写着「色彩结构」（换题保留）和「本例配色」（换题就换），网址加 `?pal=alt` 能看到同一套做法换成另一个题材的配色。你的颜色从你的主角、现场的光和题目的情绪里推。

## 怎么用

1. 按 `风格.md` 判断好用哪种风格、定好你自己的色彩体系，再打开对应编号的样张：先在浏览器里看它播一遍（没法看就读代码），再读文件头的「招牌细节」「做粗了 → 做精」；文件头有「搬到讲解里」的（01、02、06、07、08、11），先读它：样张里的哪个节拍对应讲解里的哪种讲法。
2. 按文件头的「技法目录」找到要用的代码段（`━━ T3 …… ━━` 分隔），搬进你的成品，换成你的颜色、尺寸和主体。
3. **搬做法，不搬主体、配色、文案和版式。** 你的画面画你的例子、用你的颜色、用你的现场里本来会有的小字。
4. **页面上的东西自己设计。** 大字、播放控制、出处这些东西样张里没有；要有哪些、各自装什么，见 `形式.md`「页面上要有的东西」；放在哪、长什么样、怎么出现，按你的风格和题目的现场自己定。样张的播放代码只是让它自己循环播的最简单的时间线，不要照抄。
5. 样张为了零依赖只用了系统字体和画出来的字形；成品可以按 `风格.md`「字体」嵌开源字体的子集。
6. 样张都没有声音，只为演示画面。成品要有声音，按 `风格.md`「声音」自己合成；不因为样张是静音的，就交静音的片子。
