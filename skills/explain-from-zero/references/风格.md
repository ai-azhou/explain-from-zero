# 风格：先定一个世界，挑一种做法，做足六层

## 标准

把内容遮掉，单看画面，也得是一件人愿意多看两眼、愿意转发的作品，一眼看上去是设计师做的。讲得清只是及格。底色换了、构图对了，但平涂色块、没有材质和光、物件只有一层细节、系统黑体两档字、默认样子的按钮，还是粗糙，算没做完。

## 怎么定

1. **先用一句话写下这部片的世界**：主角是什么东西、什么质感，它在什么现场（天空、夜里、厨房、舞台、屏幕里、水下、机器内部……），光从哪来、是什么时候，听起来是什么样（见下面「声音」）。写在页面开头的注释里，全片不换。
2. **自己判断用哪种画面语言：先列五个候选，再比出一个。** 用户点名的风格照做。没点名时，先写下这一题要让人看见的是哪种变化，再从下面的风格词（或你想到的别的风格）里挑五个候选，每个用一句话说清：它会怎么画这一题的变化，气质和题目、和看的人配不配，用在这一题上最大的短板是什么。然后把五个放在一起比，选出最合适的一个（最多再搭一种），把五个候选和选中的理由写在「世界」那句注释旁边。翻页手稿最容易被当成万能的默认：只有它的长处正是这一题最需要的，才选它。定了以后打开 `样式库/` 里对应编号的样张：看它播一遍，读文件头的「招牌细节」「做粗了 → 做精」，把要用的技法段搬进你的成品。要借别的风格里的某样做法（引线标注、跳动读数、对比镜……），查 `样式库/README.md` 的索引。
3. **自己定色彩体系**：风格决定怎么画，颜色由这个题目决定。从主角本身的颜色、现场的光和时间、题目的情绪里推：几种颜色，谁是底，谁是主角，哪个只留给答案那一下。写在「世界」那句注释旁边。样张里的颜色来自样张自己的主体，换了题目就换；不要因为样张的颜色和题目不配就放弃一种风格，也不要把它的颜色搬过来。少数风格的颜色是它语言的一部分（原色网格的高饱和原色、霓虹录像带的霓虹夕阳、工程蓝图的晒图色、遥测界面的单色发光），用它们之前想清楚这套颜色和题目配不配：配就用；不配就保留它的色彩结构、换色相，或者换一种风格。
4. **画的是那个具体例子，不是概念。** 画转出来的那颗球、那扇门、冰箱里那盘菜、账本上那笔钱；不画「概率」「现金流」的方块和箭头。概念靠例子的变化讲出来。
5. **每一镜动手前先一句话写画面**，像给美术的分镜：画面里有什么、什么在动、光和镜头怎么走、怎么接到下一镜（见 `形式.md`）。亲手试那一镜还要写：请他做什么、他做了画面怎么变、他不动手时怎么自己演示。写不出画面的镜头，说明这一步还没想好。
6. **开场那一镜和给出答案那一镜当海报画**：构图、层次、光、材质、标题字都讲究。第一帧就是完整构图。
7. **画面里的东西要参与讲解**：每一镜的主视觉里至少有一样东西肉眼可见地变化（挪动、增减、变形、换状态）；只换上面的字不算；同一个构图最多停两镜。摆着不动的道具不能占画面的大头。
8. 大字、播放控制、出处这些页面上的东西（见 `形式.md`）也是这个世界里的东西：长什么样、放在哪，从这一题的现场和你定的风格里自己设计。样张里没有这些东西，也不要套用你见过的其他成品的样子。

## 六层做工

风格不同，层数不能少。交付前一层层对一遍：

1. **色和构图**：色彩体系有主次（见上面第 3 步）；主体占满画面，有前中后层；主体放在一个「现场」里（有厚度的地台、画板、屏幕、桌面、地面倒影），不浮在一块色底上。
2. **材质和光**：至少两样。纸纹、颗粒、网点、辉光、柔影和接缝暗部、高光、景深虚化、玻璃折射……用 SVG 滤镜、Canvas 或着色器生成，不搬图片。
3. **细节三级**：大形 → 中细节 → 微细节（排线、斑点、铆钉、刻度、窗格）。角落有这个现场本来就会有的小字（按你的现场定，不照搬样张里的场记号、图号）。只当装饰、不用读的小字可以小；读数和道具上要读的字，按手机 390 宽看不小于 12 像素。
4. **字**：标题用这个风格的显示字（合适的开源字体，或用 SVG、Canvas、CSS 画出来的手写字、镀铬字、像素字、充气字、多层描边字……，见下面「字体」）；字分三档：超大的字或数字 / 正文 / 字距拉开的小标或等宽数据。
5. **动效**：预备 → 动作 → 过冲回落；挤压拉伸；一组东西错峰出现；镜头推近、拉远揭示；镜与镜之间接着变过去；按风格挑帧率（手绘一拍二、拼贴十二帧一跳、像素逐格）。匀速和淡入淡出不能当主要的动法。
6. **后期**：暗角、颗粒、辉光、扫描线、色散……按风格挑一两样，要轻，不压字。

## 风格词

括号里是 `样式库/` 的编号。每条写的是这种画面语言做精了是什么样、擅长表现什么；颜色不在这里，由你按题目定。

- **翻页手稿**（01）：线条每两帧抖一下，墨线有粗细和顿笔，阴影用排线，纸有纹理，颜色像水彩晕开；平涂只用两三色；标题是描边加错位暗影的手绘胖字，一笔笔写出；角落有手写场记号。擅长让东西自己「演」：弹、压、碰、冒、亮，带着手作的温度。
- **微缩沙盘**（02）：没有透视的微缩模型，方块有厚度和倒角，侧面比顶面暗、接缝有柔影；先一格格长出白模，再整片上色；数据牌立在等轴面上。擅长空间布局和系统：谁挨着谁、谁连着谁、哪一块在干什么。
- **扁平矢量**（03）：少数几种纯色、零阴影，层次靠色块叠放；靠节奏讲：落地压扁、过冲回弹、错峰升起、快速横移带运动模糊。擅长轻快地串起一条因果链、把几种做法并排比。
- **线条动画**（04）：大片留白，一根细线带着发光的笔尖一笔画到底，镜头跟着笔走，最后一处填色点亮。擅长推导和过程：一步接一步，不能跳。
- **3D 渲染**（05）：大面积柔光、接触阴影、亮面高光和边缘光、浅景深；成千上万个小物铺开，主体落下压陷再回弹。擅长尺度、数量、软硬轻重、一次碰撞引起的连锁。暗场发布片也算这一类：一束侧光，主体悬浮，零件沿一根轴展开。
- **形状接力**（06）：带颗粒的色面，一个形状连续变成下一个，背景色面跟着整块切换；形状上一道折纸暗面。擅长 A 变成 B、状态转化和循环。
- **拆解图鉴**（07）：干净的浅底（点阵或刻线网格），写实质感的物件带粗白边和投影；引线标注分三层（粗体名称、字距拉开的小字、方块标签）；超大计数逐个跳数；镜头在大画布上推拉平移。擅长拆开看、清单、「到底有多少」。
- **遥测界面**（08）：暗底上单一发光色的界面，刻度环或扇形刻度、扫描线和线框体在转，四周是密而小的遥测数据，衬托一个大读数；状态变化时整屏换成另一种发光色；亮部有辉光。擅长定位、识别、测量、系统一步步判断。
- **拼贴剪报**（09）：纸片做底，网点印刷的剪纸带白边和投影，撕边纸、胶带、勒索信式字块、印章；十二帧一跳的卡顿。擅长把一句话、一张单据剪开再拼回去看。
- **弥散渐变玻璃**（10）：缓慢流动的光团上浮着磨砂玻璃卡片（内描边、斜高光、细噪点），卡片分层视差，界面元素自己在动，透镜划过放大下面的字。擅长界面和软件、层级和先后、「它在想什么」。
- **原色网格**（11）：纸面、淡网格和套准十字；高饱和的纯色（红黄蓝或印刷的青品黄）加黑，圆、方、三角踩着节拍滑入、咔哒对齐，叠在一起时叠印出第二种色；超粗大字或超大号数字。擅长比例、规则、对比，「几样东西怎么拼成一个」。
- **霓虹录像带**（12）：录像带开场，向前滚动的霓虹透视网格，横条切开的渐变落日，镀铬斜体立体字和霓虹手写字；扫描线、色散、辉光。擅长速度、时间、冲向极限、回放。
- **像素风**（13）：低分辨率画布整数倍放大，多层视差，抖动渐变；同一张画换调色板表示时间流逝；对话框逐字打出，像素大标题；显像管圆角暗角。擅长规则、闯关、「做对了才能过」、时间流逝。
- **液态流动**（14）：会反光的地面，果冻质感（透光、深边、两道高光、折射后面的东西），落地压扁、拉丝、融合。擅长溶解、扩散、融合和分裂。
- **综艺花字**（15）：大字三层描边加错位硬投影、倾斜、弹簧弹出；放射速度线、爆炸星、描边贴纸、警示胶带条。擅长把一个反差或结论「爆」出来，让人记住、愿意转发；气质偏闹。
- **数据特稿**（16）：纸面、墨色字，一种强调色、其余全灰；发丝级坐标和网格，注释直接写在数据旁边，线从左往右画出、数字滚动。擅长随时间变化、比大小、多了多少。
- **工程蓝图**（17）：晒图纸的质感，两级网格，尺寸线和剖面排线，图框标题栏；先描轮廓再补尺寸，零件沿轴爆炸展开再合拢。擅长结构、装配、「改了哪里」。
- **自然纪录片**（18）：光来自画面里的光源，前中远三层加雾，体积光、颗粒和暗角，镜头极慢；字距拉开的细字幕条。擅长尺度、距离、慢慢发生的自然现象。

底色暗的时候字难压住：字放在实底带、暗角或够暗的玻璃上。用户点名的风格不在上面时，先想清楚这种风格的六层各是什么再做。用户点名某家公司、某部片子的感觉时，同样翻译成做法和质感来做；成品里不写名字、不放标志、不仿任何能认出来的画面，不搬图片、视频、音乐和字体文件。

能转的真三维只在用户点名、或不转一下真看不懂结构时做；用着色器画出光和材质（3D 渲染、液态流动、弥散渐变玻璃、自然纪录片的样张都是这么做的）不受这条限制。用了 WebGL 就要有退路：拿不到时画一张静态近似，字和控件照常。

## 不要

- 不要照搬样张的主体、配色和版式；样张只教做法。
- 不要套一个默认底色：深灰蓝底加荧光强调色、米黄纸底配朱红印章和木纹、暗场加一盏吊灯，都是模板。
- 不要把概念画成方块、圆点、箭头连线的示意图。
- 不要几何图形拼人物、卡通脸、emoji 当插图；人画不好就画背影、手、局部和器物。
- 不要浏览器默认的按钮、滑块、折叠三角。
- 不要把文字放进色块就当画面；不要开场空舞台再慢慢长出来。
- 不要在页面里从网上实时加载字体、脚本和任何外链（中国大陆常加载不出，断网也打不开）。

## 字体

可以用开源字体，不一定只用系统字体。挑许可允许嵌入和再分发的（比如 SIL Open Font License），按风格挑显示字（手写、圆体、粗黑、宋体、像素……），正文用一种好读的。

- 只取页面上实际用到的字做子集，转成 base64 写进页面的 `@font-face`；整页的字体加起来控制在约 2 MB 以内，中文字体不做子集动辄十几 MB，不能整套塞进去。
- 注释里写上用了哪款字体和它的许可。
- 后面接上系统字体栈当后备，字体没嵌进去时页面照样能读。
- 做子集要用到电脑上没有的工具时，照入口「一直要守的」先问；用户不同意或没回复，就用系统字体，特殊字形用 SVG、Canvas 画。

## 声音

成品要有声音：一段背景乐，加上关键变化处的短音效，全部在页面里用代码现场合成（比如浏览器自带的 Web Audio）。

建议：

- **风格定音色，题目定情绪。** 音色从这个世界里来：主角是什么做的、现场里本来会有什么声音。快慢、明暗、疏密跟着题目和这一步的情绪：讲问题、讲代价的一步往下走、偏暗，给出答案那一下往上走、亮一点；情绪不要带反。
- **背景乐是一段悦耳的简单旋律。** 有一条听得出、哼得出的短旋律（在中音区，几小节一句），配上简单的和弦和节奏；旋律的性格（快慢、明暗、用什么音色）贴着题目和看的人，听着不突兀。全片随镜头有发展：开场把旋律引出来，给出答案那一镜变一下（换和弦、加一层，或停一拍让音效出来），收尾回到主音、慢慢收掉；不是一小段反复循环。音量低于音效，不抢字。
- **先写谱，再合成。** 动手前把背景乐写成一张音符表：什么调、几拍、每小节的和弦、旋律每个音的音高和时值、到哪一镜怎么变；再照着表合成。
- **背景乐跟着片子的时间线走**，像成片的音轨：片子播到第几秒，背景乐就在它的第几秒；不按镜头切段，自动播放时镜头之间不断。片子停在亲手试那一镜等他时，背景乐压低、在这一段里轻轻延续，接着播时回到时间线上。
- **音效少而准。** 只配在画面里看得见的关键变化上（落下、咬合、对上、揭晓、数字跳到终值），一镜一两下；同一种动作始终是同一个声音，全片三五种就够。声音和动作同一刻发生，跟画面用同一个时钟。亲手试时给一下轻的反馈，连续拖动时不连成一串。
- **响度。** 背景乐明显低于音效；有配音时两者都让开人声。总输出加限幅，不爆音。手机外放也要听得到：旋律和主要的声音放在中频，不靠低音撑，高频不刺耳。每个声音的起止都有极短的渐入渐出，不出咔哒声。
- **怎么开声音。** 浏览器不让网页一打开就出声：画面照样自己播；开声音的入口一眼看得到、不挡画面，点一下就有声音，再点一下就关；也可以在他第一次点页面时顺手接上。中途打开时，从片子当前的时刻接上，不从头起。

绝对不能：

- 不拿持续的长音、低频嗡嗡的铺底当背景乐；听不出旋律的不算背景乐。
- 不放、不从网上加载任何音频文件；不仿任何能认出来的旋律和声音（歌曲、广告歌、影视配乐、系统提示音、游戏和品牌的标志性音效）。
- 不靠声音讲内容：关掉声音也要完整看得懂。
- 不为了出声挡住画面：不做盖住画面的「点击开始」；声音没开、合成出错时，画面照播、不报错。
- 不吓人、不刺耳：不突然很响，不用警报、尖叫、心跳、恐怖音效；给孩子看的更要轻。
- 不用声音替人推情绪：讲钱、讲健康的题，不用中奖、金币、欢呼、倒计时催促这类声音。
- 声音跟着片子的时间线走，和视频一样：暂停就停，继续时从停下的地方接着放；拖进度、跳镜时，背景乐跳到那一刻该在的位置接着放，不从头起，也不顺着自己原来的位置往下走；跳过的那几镜的音效不补放；切到别的标签页、播完时声音停。
- 不给每个动作都配声音。

## 文字：每句话都要有用

- 每句话带一个新信息；删掉只预告下文的句子。
- 不用「不是 A，而是 B」制造对比；只有用户真有这个误解时才纠正，并先把它原样摆出来。
- 不写格言、金句和升华式收尾；标题说出具体的问题或答案，不用「从零讲 · X」「一文看懂 X」。
- 少用「其实」「本质上」「关键在于」「简单来说」；不硬凑三项排比；不用一串短句制造戏剧感。
- 交付前把大字按顺序抽出来通读一遍：只看这一层能不能讲通整件事。
